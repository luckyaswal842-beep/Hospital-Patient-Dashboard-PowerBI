# Hospital-Patient-Dashboard-PowerBI
An interactive hospital analytics dashboard designed to track patient details, billing, and treatment patterns, enabling healthcare providers to improve decision-making, optimize costs, and enhance patient care.
## 📌 Project Overview

Efficient patient management and cost tracking are critical in healthcare. This project analyzes hospital data to provide insights into patient information, billing, treatment timelines, and resource utilization.

The dashboard helps stakeholders monitor patient status, understand financial distribution, and track treatment activities over time.

## 🎯 Objectives
- Monitor patient details and admission records
- Analyze hospital charges and billing patterns
- Track treatment and medication trends
- Provide insights for better hospital management

## 📂 Dataset
Source: Hospital dataset from a YouTube tutorial 
- Key Features:
- Patient Name
- Age & Gender
- Diagnosis
- Admission & Discharge Date
- Billing & Charges
- Medication tracking
